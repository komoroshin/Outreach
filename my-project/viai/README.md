# VIAI · предложение от Океан Тех (Ocean Tech)

Прицельное предложение для VIAI (Абу‑Даби): Healthy4U как white‑label клинический слой для V‑Clinic.

## Что в папке

- `index.html` — веб‑страница предложения (английский, дизайн‑система Океан Тех, шрифты в `fonts/`).
- `deck.html` → `deck.pdf` — дека на 8 слайдов для пересылки внутри VIAI и инвесторам. Пересобрать: `chromium --headless --print-to-pdf=deck.pdf deck.html` (см. `build-pdf.sh`).
- `email.md` — сопроводительное письмо и фолоап (английский).
- `deck-ru.html` → `deck-ru.pdf` и `email-ru.md` — русские версии для внутреннего показа коллегам (клиенту не отправляем).

## Решения, принятые при сборке

- Модель: white‑label лицензия, пилот в первой клинике → лицензия на локацию.
- Бренд: Океан Тех, по-английски **Ocean Tech** (как в официальной презентации okeantech.ru/presentation/en/), язык английский.
- Кейс GavCure показан без страны («private practice, six months, three physicians»).
- Цены не названы: «после discovery‑звонка».

## Что проверить перед отправкой

1. Слайд «Built for the Gulf»: арабский интерфейс, размещение данных в ОАЭ (UAE cloud / on‑prem), интеграция с Malaffi помечены как **Pilot scope**, не как готовые. Убедиться, что команда готова это сделать в рамках пилота.
2. Интеграция Engo/кольца через приложение VIAI помечена как pilot — у VIAI пока нет публичного API, это обсуждается на discovery.
