# cold-email — холодное письмо новому лиду

## Вход

Компания + ЛПР + ресёрч по ним (боль, триггер) — обычно из `account-researcher` или из контекста разговора.

Оффер и кейсы — из бизнес-CLAUDE.md (в практикуме — `aximo-CLAUDE.md`; в реальном проекте — `CLAUDE.md` проекта).

## Структура письма

1. **Тема** — скучная, не маркетинговая, будто прислал коллега или клиент.
2. **Opener** — сильный первый абзац, который цепляет и не выдаёт, что письмо холодное. Никакого «меня зовут… мы компания…».
3. **Почему именно им** — видим у них конкретную проблему, которую решаем (из ресёрча).
4. **Почему сейчас** — триггер/срочность (наняли, выросли, запустили, сезон).
5. **Что предлагаем + how it works** — кратко, 1–2 предложения.
6. **Social proof** — «помогли [похожей компании] добиться [результата]», только из реальных кейсов.
7. **Один простой следующий шаг** — лёгкий (15 минут созвона) или квалифицирующий вопрос — что лучше ложится в письмо.

## Тон

Человеческий, plain text, абзацы по 2–3 предложения. Язык — под адресата: российской компании пишем по-русски, зарубежной — по-английски.

**DO:** персональный хук из ресёрча, один оффер, короткие абзацы.
**DON'T:** «надеюсь, у вас всё хорошо», дамп фич, фейк-персонализация, маркдаун, маркетинговый пафос.

## Формат вывода

```
Тема: ...

<тело письма, plain text, готово к отправке>
```

По желанию — короткий LinkedIn-коннект (<300 символов). Затем 2–3 строки «почему так» (короткий разбор решений). Пометка **«черновик — проверь и отправь сам»**.

## Гейты

- Только черновик — никогда не отправлять самостоятельно.
- Social proof — только из реальных кейсов (бизнес-CLAUDE.md / закрытые сделки), не выдумывать.
- Чего нет в ресёрче — плейсхолдер `[…]`.
