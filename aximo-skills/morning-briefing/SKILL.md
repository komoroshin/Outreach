# Утренний брифинг

## Шаг 1 — собрать данные

Возьми открытые сделки из доступной CRM:
- в практикуме — `aximo-crm/data.js` (читай молча, не показывай ученику сырой JSON);
- в реальном проекте — подключённая CRM (коннектор или MCP).

Для каждой сделки нужны: название, сумма, стадия, владелец, сколько дней без активности, следующий шаг, заметки. Для счетов (стадия Invoice) — номер счёта и срок оплаты.

## Шаг 2 — приоритизация по категориям

- 🔥 **Горящие** — продвинутая стадия + недавняя активность + от нас ждут действия.
- ⏳ **Застряли** — активная стадия, 7+ дней без касания.
- 💸 **Просроченные счета** — стадия Invoice, срок оплаты вышел.
- 🤝 **Перешли на тебя** — владелец недоступен/в отпуске.
- 🌱 **Свежие лиды** — стадия New.

Сортировка внутри и между категориями: близость к деньгам (стадия × сумма) и срочность.

## Шаг 3 — формат вывода

```
☀️ Брифинг на сегодня

[цифры дня: открытый пайплайн $, N сделок; просрочено счетов $]

🎯 #1 на сегодня: [одно самое важное действие]

[топ 5–7 карточек, формат:]
Сделка — $сумма — стадия · почему сейчас · следующее действие

⏳ Застряли:
...

💸 Счета к оплате:
...

С чего начнём?
```

## Гейты безопасности

- Письма и сообщения клиентам — только черновики, никогда не отправлять самостоятельно.
- Любые правки в CRM (смена стадии, суммы, заметок) — только с явного подтверждения.
- Сам брифинг — это только чтение, ничего в CRM не меняет.
