# call-summary — саммари звонка

## Вход

Транскрипт или заметки звонка — файл через `@` либо просто текст. Чем больше деталей на входе, тем точнее саммари.

## Что делает

Читает транскрипт и вытаскивает: участников, ключевые темы, договорённости, следующий шаг (с ответственным и сроком), возражения, сигналы (бюджет/сроки/ЛПР).

## Формат вывода (коротко, для РОПа)

```
🤝 Саммари: <сделка>
<участники / дата>

Коротко: 1–2 предложения.

Обсудили:
- ...
- ...

Договорились:
- ...

Следующий шаг: кто / что / срок.

Возражения/риски:
- ...

Сигналы: бюджет / сроки / ЛПР (если были).
```

## Дополнительно (по желанию, с гейтом)

Может собрать **черновик** follow-up-письма клиенту по итогам звонка — только черновик, отправляет человек.

## Гейты

- Ничего не выдумывать сверх транскрипта.
- Письма — только черновиком, никогда не отправлять самостоятельно.
