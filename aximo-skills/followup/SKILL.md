# followup — батч-фолоапы

## Параметры

- `N` — порог тишины в днях, по умолчанию **7**.
- Стадии в фокусе — по умолчанию **Квалификация + Переговоры**.

## Проход 1 — дешёвый отбор

Пройти по списку сделок (в практикуме — `aximo-crm/data.js`; в реальном проекте — рабочая CRM). Взять **только** стадию и дату последней активности.

Оставить сделки, у которых стадия ∈ {Квалификация, Переговоры} **И** с последней активности прошло **> N дней**.

**Заметки и переписку на этом шаге не читать** — в этом вся экономия токенов и времени. Недавно активные сделки и сделки вне фокусных стадий отсекаются здесь же, до дорогого шага.

## Проход 2 — глубоко, только по шортлисту

По каждой отобранной сделке поднять последний контекст (последняя заметка / последнее письмо / на чём встали) и написать короткий пинг (2–4 предложения):
- зацепка из контекста (на чём остановились);
- повод/ценность, а не «ну что там?»;
- один лёгкий следующий шаг или вопрос;
- спокойный тон, без давления.

Язык — под адресата (рус/англ).

## Формат вывода

Сначала сводка: «просмотрено сделок X, в фокусе (Квал/Перег) Y, подвисли (>N дней) Z».

Затем по каждой подвисшей:
```
Сделка — стадия — тишина N дней
<черновик пинга>
```

Пометка **«черновики — проверь и отправь сам»**.

## Гейты

- Только черновики — никогда не отправлять самостоятельно.
- Не трогать недавно активные сделки и сделки вне фокусных стадий.
- Ничего не выдумывать сверх контекста.
