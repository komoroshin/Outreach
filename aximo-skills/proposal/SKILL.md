# proposal — КП со сметой

## Вход

Название сделки + набор требований (если не передан — взять из контекста сделки в CRM или спросить).

## Шаг 1 — контекст

Поднять сделку из CRM (в практикуме — `aximo-crm/data.js`; в реальном проекте — рабочая CRM): боль клиента, что обсуждали, на чём остановились. Если есть транскрипт звонка или переписка — прочитать.

## Шаг 2 — активы

Взять шаблон `aximo-templates/proposal-template.html` и математику расчёта `aximo-templates/pricing-model.md` (в реальном проекте — свои шаблон и модель).

## Шаг 3 — персонализация

Заполнить токены `{{...}}` и блоки, помеченные в шаблоне как персонализируемые: задача клиента его словами, наше решение, объём/этапы, следующий шаг. Статичные блоки (о нас, «Почему Aximo») — оставить как есть, только подставить релевантные реальные кейсы из бизнес-CLAUDE.md (в практикуме — `aximo-CLAUDE.md`; в реальном проекте — `CLAUDE.md` проекта) или закрытых сделок — не выдумывать. Контакт — из бизнес-CLAUDE.md / реквизитов компании.

## Шаг 4 — смета

Посчитать **строго по `pricing-model.md`** под набор требований клиента. Собрать строки таблицы, этапы (если нужна поэтапность) и ИТОГО. Нестандартные позиции, которых нет в модели, — пометить `[уточнить у CEO]`, суммы не придумывать.

## Шаг 5 — сохранить и сделать PDF

Сохранить готовое КП в `aximo-templates/proposals/<client>-proposal.html` (имя файла — латиницей). Затем красиво экспортировать в PDF скриптом:

```
python3 aximo-templates/html2pdf.py aximo-templates/proposals/<client>-proposal.html aximo-templates/proposals/<client>-proposal.pdf
```

Ручную «Печать → Сохранить как PDF» не использовать. Если скрипт не смог собрать PDF (например, в облаке нет браузера) — сказать об этом спокойно, HTML-версия уже готова и годится, PDF можно собрать позже с компьютера.

## Формат КП

Обложка → задача клиента → решение (+3 шага) → объём/этапы → смета → почему Aximo → следующий шаг.

## Гейты

- Цифры сметы — только из модели, ничего не выдумывать.
- КП клиенту не отправляется из навыка — только черновик, отправляет человек.
- Валюта — `$`.
