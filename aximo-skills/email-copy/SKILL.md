# email-copy — письмо по сделке

## Вход

Название сделки + (необязательно) цель письма: реанимация / следующий шаг / ответ на вопрос / холодный первый контакт.

## Шаг 1 — собрать контекст

Поднять сделку из CRM (в практикуме — `aximo-crm/data.js`; в реальном проекте — рабочая CRM): заметки, переписку, стадию. Если у сделки есть транскрипт (`aximo-templates/transcripts/...`) — прочитать его.

Понять: на чём стоит сделка, чего ждёт другая сторона, **кому** пишем и что для этого человека важно.

## Шаг 2 — определить тон/оффер

Взять позиционирование и тон из бизнес-CLAUDE.md (в практикуме — `aximo-CLAUDE.md`; в реальном проекте — `CLAUDE.md` проекта).

## Шаг 3 — написать письмо

Принципы:
- конкретная **тема**, не «Касательно сотрудничества»;
- **зацепка** из контекста — ссылка на реальный звонок/договорённость;
- **ценность, а не просьба** — дать то, чего ждут, а не «как дела?»;
- **один чёткий следующий шаг** — конкретный и лёгкий;
- **тон под адресата** — закрыть именно его тревогу;
- коротко, без воды и канцелярита;
- никаких «просто проверяю».

## Формат вывода

```
Тема: ...

<тело письма, готовое к отправке>

Кому/от кого: ...
```

**Черновик — проверь и отправь сам.**

По желанию — второй вариант, короче или в другом тоне.

## Гейты

- Только черновик — никогда не отправлять самостоятельно.
- Не выдумывать факты/цифры, которых нет в контексте — если не хватает данных (точный SLA, дата), ставить явный плейсхолдер `[…]` и сказать, что подставить.
