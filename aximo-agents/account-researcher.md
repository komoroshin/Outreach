# account-researcher — агент ресёрча для холодного outbound

**Кто это:** отдельный «сотрудник», который по сайту компании находит ЛПР, их рабочие почты и LinkedIn — работает в своём контексте.

**Как запустить:** `/account-researcher Компания1 (сайт1), Компания2 (сайт2)` — можно сразу по нескольким компаниям, тогда для каждой запустится отдельный параллельный агент.

**Что делает:**
- изучает сайт компании — чем занимается, размер, гео;
- ищет в вебе триггеры и новости;
- находит ЛПР на LinkedIn (публичные данные);
- если подключён коннектор Hunter — ищет рабочие почты по домену компании;
- для российских компаний может дополнительно взять руководителя по ИНН через DataNewton.

**Что отдаёт:** 1–3 ЛПР на компанию (имя, должность, почта, LinkedIn), почему именно они, и короткий хук для холодного захода.

**Инструменты:** только чтение и поиск (Read, WebSearch, WebFetch, + Hunter, если подключён) — ничего не меняет.

В реальной работе наведи `account-researcher` на свой список компаний-целей — сработает так же.
